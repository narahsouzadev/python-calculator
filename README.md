# Interactive Python CLI Calculator with Memory (MS)

![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat&logo=python&logoColor=white)
![Status](https://img.shields.io/badge/status-completed-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

A command-line calculator supporting basic arithmetic operations (addition, subtraction, multiplication, and division) inside a continuous execution loop. It features an accumulator memory register (MS) allowing users to add (M+), subtract (M-), or discard results across multiple calculations.

## 🎓 Academic Context
Developed as the final project for the **Algorithms and Programming Logic** course in the **Systems Analysis and Development** degree program.
